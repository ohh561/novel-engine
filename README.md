# 🖊️ Novel Engine — 长篇小说写作引擎

一个完整的长篇小说写作引擎，可以独立驱动一部 500+ 章的长篇小说。

## 这是什么？

Novel Engine 是一套模块化的写作系统，帮你规划、写作、监控一部长篇小说。它不是 AI 写作工具，而是一个**结构化的故事管理系统**——管理世界观、情节、角色、伏笔、时间线，确保数百章下来逻辑一致、节奏合理、伏笔不断线。

## 核心特性

- **四层金字塔情节系统** — 世界观→卷大纲→幕大纲→情节节拍，层层驱动
- **三级伏笔系统** — 全书级/卷级/章节级伏笔，自动追踪埋入和回收
- **角色成长系统** — 性格维度、技能树、携带物品、关系矩阵，随剧情演变
- **读者旅程追踪** — 情绪曲线、子线监控、节奏热力图
- **主线监控** — 自动追踪主线进展，偏离/拖沓/断线预警
- **自审系统** — 逻辑一致性、节奏、人物、去AI味，每章写完必须检查
- **写作引擎** — 模块协作、自动丰富、依赖检查、故障恢复
- **冷启动模板** — 新建小说时复制模板即可开始

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/ohh561/novel-engine.git
cd novel-engine
```

### 2. 了解目录结构

```
novel-engine/
├── engine.md              ← 引擎总纲（模块协作规则）
├── naming.md              ← 命名规范
├── config.md              ← 引擎配置
├── worldview/             ← 顶层世界观（每本小说不同）
├── plot/                  ← 情节系统（每本小说不同）
├── persistent/            ← 贯穿性系统
│   ├── characters/        ← 角色档案
│   ├── foreshadow.md      ← 伏笔系统
│   ├── timeline.md        ← 时间线
│   ├── index.md           ← 全局ID索引
│   ├── monitor.md         ← 主线监控
│   ├── dashboard.md       ← 健康仪表盘
│   └── reader-journey.md  ← 读者旅程
├── writing/               ← 写作技术层
│   ├── guide.md           ← 写作指南
│   ├── critic.md          ← 自审系统
│   ├── update-checklist.md← 更新清单
│   ├── revision.md        ← 修订流程
│   ├── quality.md         ← 质量标准
│   ├── tutorial.md        ← 从零教程
│   └── annotated-example.md ← 带注释示例
├── template/              ← 冷启动模板
└── chapters/              ← 正文
```

### 3. 开始写作

```bash
# 方式一：从模板新建
cp -r template/ my-novel/
cd my-novel/

# 方式二：直接在本目录写
# 填写 worldview/, plot/, persistent/ 然后开始写
```

按 `writing/tutorial.md` 的 10 步教程开始。

### 4. 写作流程

每写一章的完整流程：

```
1. 生成上下文包（读节拍+世界+持久化+写作指南）
2. 写正文（3000-5000字）
3. 自审（逻辑/节奏/人物/伏笔/去AI味）
4. 更新文档（时间线→主角→角色→伏笔→索引→监控→读者→仪表盘）
5. 主线监控检查
6. 读者旅程检查
7. 保存正文
```

## 目录说明

| 目录 | 说明 | 需要改动吗 |
|------|------|-----------|

| `plot/` | 情节系统 | 每本小说不同 |
| `persistent/` | 贯穿性系统 | 随剧情更新 |
| `writing/` | 写作技术层 | 一般不改 |
| `template/` | 冷启动模板 | 复制用，不改 |
| `chapters/` | 正文 | 写作产出 |
