# 伏笔系统

> 三级伏笔：B-（全书级）/ V{N}-（卷级）/ C-（章节级）

| 状态 | 含义 |
|------|------|
| 🔴 计划中 | 已规划但未埋入 |
| 🟡 已埋入 | 已在正文中埋入 |
| 🔵 已暗示 | 被后续提及/强化 |
| 🟢 已回收 | 已在正文中揭示 |
