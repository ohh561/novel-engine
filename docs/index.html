🖊️ Novel Engine

一个完整的长篇小说写作引擎，可以独立驱动一部 500+ 章的长篇小说。

⭐ GitHub 📖 从零教程 📦 冷启动模板

核心特性

🏗️

四层金字塔情节系统

世界观→卷大纲→幕大纲→情节节拍，层层驱动。情节优先，章节为切分单位。

🔗

三级伏笔系统

全书级/卷级/章节级伏笔，自动追踪埋入和回收。数百章伏笔不断线。

👤

角色成长系统

性格维度、技能树、携带物品、关系矩阵。角色随剧情演变，关系自动同步。

📈

读者旅程追踪

情绪曲线、子线监控、节奏热力图。确保不出现连续平淡或连续紧张。

🎯

主线监控

自动追踪主线进展，偏离/拖沓/断线预警。数百章不迷路。

🔍

自审系统

逻辑一致性、节奏、人物、去AI味。每章写完必须检查，发现问题立刻纠正。

⚙️

写作引擎

模块协作、自动丰富、依赖检查、故障恢复。改了A自动检查B、C、D。

🚀

冷启动模板

新建小说时复制模板即可开始。最小启动只需填4个文件。

写作流程

1

生成上下文包

读取节拍、世界设定、持久化文件、写作指南

2

写正文

3000-5000字，按写作指南执行

3

自审

逻辑/节奏/人物/伏笔/去AI味检查，发现问题立刻纠正

4

更新文档

时间线→主角→角色→伏笔→索引→监控→读者→仪表盘

5

主线监控

检查是否偏离主线，是否拖沓或赶进度

6

读者旅程检查

子线是否断线，节奏是否失衡

7

保存正文

输出到 chapters/volX-chXXX.md

开始你的长篇小说

克隆模板，填入设定，开始写作。就这么简单。
