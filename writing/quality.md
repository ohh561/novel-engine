# 质量评估标准

> 自审清单告诉你"检查什么"，本文件告诉你"到什么程度算通过"。

---

## 评分标准

每章写完后，对以下维度打分（1-5分）。低于3分的维度需要修改。

### 1. 逻辑一致性（目标：5分）

| 分数 | 标准 |
|------|------|
| 5 | 所有设定前后一致，时间线合理，因果链完整 |
| 4 | 基本一致，有1-2处小瑕疵但不影响理解 |
| 3 | 有1-2处逻辑问题，但不影响主线 |
| 2 | 有明显逻辑漏洞，影响理解 |
| 1 | 逻辑混乱，前后矛盾 |

### 2. 节奏（目标：4分+）

| 分数 | 标准 |
|------|------|
| 5 | 长短句交替，紧张舒缓交替，段落变化丰富 |
| 4 | 节奏整体流畅，偶有平淡段落 |
| 3 | 节奏基本OK，但有2-3段连续同质 |
| 2 | 节奏单调，像机关枪一样均匀 |
| 1 | 节奏混乱，没有起伏 |

### 3. 钩子（目标：4分+）

| 分数 | 标准 |
|------|------|
| 5 | 开头100字有强钩子，每500字有微钩子，结尾有钩子 |
| 4 | 开头和结尾有钩子，中间有1-2个微钩子 |
| 3 | 开头或结尾有钩子，但中间平淡 |
| 2 | 开头平淡，中间平淡，结尾平淡 |
| 1 | 完全没有吸引力 |

### 4. 人物一致性（目标：4分+）

| 分数 | 标准 |
|------|------|
| 5 | 每个角色的言行完全符合性格档案，对话有区分度 |
| 4 | 主要角色一致，配角有1-2处小偏差 |
| 3 | 主角一致，配角有偏差 |
| 2 | 主角有偏差 |
| 1 | 角色行为混乱，不符合设定 |

### 5. 展示不叙述（目标：4分+）

| 分数 | 标准 |
|------|------|
| 5 | 情绪全部用行动展示，没有"他感到""他想" |
| 4 | 基本用行动展示，有1-2处直接叙述 |
| 3 | 大部分用行动展示，但有3-5处直接叙述 |
| 2 | 大部分是直接叙述 |
| 1 | 全是"他感到""他想""他知道" |

### 6. 去AI味（目标：4分+）

| 分数 | 标准 |
|------|------|
| 5 | 禁用词0个，段落长短交替，有"AI不敢写"内容 |
| 4 | 禁用词≤1个，段落基本OK |
| 3 | 禁用词≤2个，但整体还像人写的 |
| 2 | 禁用词3+个，段落均匀，明显AI味 |
| 1 | 典型AI腔 |

### 7. 情感共鸣（目标：3分+）

| 分数 | 标准 |
|------|------|
| 5 | 读者会停下来想一下，有余韵，有触动 |
| 4 | 有1-2个触动点 |
| 3 | 有情感但不够深 |
| 2 | 情感平淡 |
| 1 | 没有情感 |

---

## 通过标准

| 维度 | 最低分 | 目标分 |
|------|--------|--------|
| 逻辑一致性 | 4 | 5 |
| 节奏 | 3 | 4 |
| 钩子 | 3 | 4 |
| 人物一致性 | 4 | 4 |
| 展示不叙述 | 3 | 4 |
| 去AI味 | 3 | 4 |
| 情感共鸣 | 3 | 3 |

**通过条件：所有维度≥最低分。**
**优秀条件：所有维度≥目标分。**
