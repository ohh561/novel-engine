# 写作技术系统

> ⚠️ 每写一章前阅读本文件。写完后用自检清单逐项检查。

---

## 一、写作流程

### 输入

写每一章时，系统自动生成**写作上下文包**：

```
=== 写作上下文包：Ch.{N} ===

【章节梗概】
- 包含节拍：B{X} ~ B{Y}
- 核心事件：{一句话概括}

【新世界设定】
- 力量体系等级：{当前涉及的等级}
- 地理：{当前场景的相关地理}
- 关键规则：{本章需要的世界观规则}

【人物状态】
- 林晨：{最新身体/心理状态，最近3章变化}
- 本章出场角色：{角色名 + 当前状态}
- 关系变化：{最近3章的关系变动}

【伏笔】
- 本章需要埋入：{V{N}-F{IDs} + 内容}
- 本章需要推进：{V{N}-F{IDs} + 当前状态}
- 本章需要回收：{V{N}-F{IDs}}

【时间线】
- 当前时间：{地球/异世界}
- 距离上一章：{时间差}

【上一节拍传递】
- {来自上一节拍的情节传递内容}

【写作要求】
- 参考 writing/guide.md 的全部要求
- 本章情绪基调：{描述}
- 本章节奏：{快/慢/交替}
```

### 执行步骤

**Step 1：场景设计**

根据节拍内容，用场景-续接模型规划：

```
场景1：
- 目标：[角色] 想要 [具体目标]
- 冲突：[什么在阻碍他？]
- 结果：[以什么结束？必须改变现状]

续接1：
- 反应：[用行动展示]
- 困境：[选择，每个选项都有代价]
- 决定：[引出下一个场景]
```

**Step 2：写作**

- 每章3000-5000字
- 遵守世界观规则
- 人物行为符合性格档案
- 不引入大纲中没有的重大设定

**Step 3：三遍去AI打磨（必须执行）**

**Pass 1 — 去泛化：**
- 抽象情绪总结 → 删，或换成具体动作
- 假深度句 → 删
- 空洞升华 → 换成动作/对话收尾

**Pass 2 — 去书面化：**
- 扫描禁用词表，逐一替换
- 对话不像人说的话 → 改成口语

**Pass 3 — 回人味：**
- 长短句交替了吗？
- 每300字至少一个感官细节
- 区分角色语气
- "AI不敢写"测试

**Step 4：自检**

用下面的自检清单逐项检查。

**Step 5：更新文档**

1. 更新 `persistent/foreshadow.md`
2. 更新 `persistent/timeline.md`
3. 更新 `persistent/characters/protagonist.md`（含"最近三章快照"）
4. 更新 `persistent/characters/cast.md`

**Step 6：输出正文**

保存到 `chapters/vol1-chXXX.md`

## 二、场景结构

### Scene-Sequel 模型

**场景三要素：**
1. **目标**：角色想要什么？（必须具体）
2. **冲突**：什么在阻碍他？
3. **结果**：必须以失败、代价或新问题结束

**续接三要素：**
1. **反应**：用行动展示（攥拳、沉默、摔东西）
2. **困境**：面临选择，每个选项都有代价
3. **决定**：做出选择，引出下一个场景

**冲突层级（好的场景至少两层）：**
- L1 物理冲突：打斗、追逐、灾难
- L2 社交冲突：欺骗、背叛、权力斗争
- L3 内心冲突：道德困境、恐惧、执念
- L4 存在冲突：命运vs自由意志、真相vs谎言

---

## 三、钩子技术

**场景开头（100字内）：**
- ✅ 动作中段切入
- ✅ 对话透露危机
- ✅ 异常细节
- ❌ 天气/景色/回忆开头

**场景中间（每500字至少一个微钩子）：**
- 新信息、意外、反转、威胁升级

**场景结尾（必须有钩子）：**
- 悬念型、反转型、决心型、威胁升级型、情感冲击型
- ❌ 不要用"他终于明白了""一切都变了"收尾

---

## 四、展示不叙述

| ❌ 叙述（禁止） | ✅ 展示（推荐） |
|---|---|
| 他很生气 | 他的指节攥得发白 |
| 她很美 | 服务员端咖啡的手晃了一下 |
| 气氛很紧张 | 帐篷里只剩下呼吸声 |
| 他很害怕 | 他发现自己的手在抖 |
| 时间过了很久 | 烟灰缸里堆了七个烟头 |

---

## 五、节奏控制

**紧张场景：**短句3-8字，大量动词，段落1-3句
**舒缓场景：**长句8-15字，感官细节丰富
**交替原则：**不要连续超过3段纯叙述或纯描写

---

## 六、角色声音

- **林晨**：冷幽默、程序员思维、比喻
- **老周**：直接、粗犷、金句
- **苏薇**：理性、精准、偶尔温柔
- **陈卫国**：简洁、权威、不废话
- **卡尔**：粗犷但有温度，骂里带关心
- **回声**：简单直接，问题直击要害
- **叶尘**：热血、正义、不服输

**对话规则：**有潜台词、推动剧情或揭示性格、口语化

## 七、去AI味系统

### 禁用词表

**一级禁用（出现即替换）：**

| 类型 | 禁用词 | 替换方案 |
|---|---|---|
| 情态 | 仿佛、好像、犹如、宛若 | 删或具体描写 |
| 程度 | 一丝、一抹、些许、几分、隐约 | 删或具体数量 |
| 动作 | 深吸一口气、缓缓、不禁、微微、轻轻、淡淡 | 具体动作或删 |
| 表情 | 眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩 | 更具体的面部动作 |
| 心理 | 心中一动、心头一震、心下了然、心中暗道、不由得 | 行动展示 |
| 判断 | 不容置疑、显而易见、毫无疑问、不可否认 | 删 |
| 过渡 | 突然、瞬间、不由自主、情不自禁 | 删或动作节奏暗示 |
| 升华 | 终于明白了、一切都变了、这一刻 | 删，具体事件代替 |

**二级禁用（每章最多1次）：**好像、似乎、仿佛、突然

### 段落规则
- 每段不超过3句
- 长短交替
- 禁止每段都有主题句

### 结尾规则

**禁止：**任何总结升华
**推荐：**动作收尾、对话收尾、数据/细节收尾、悬念收尾

### "AI不敢写"测试

每章至少1句：自嘲/承认不确定/冒犯性观点/身份降格/尴尬细节

## 八、情感共鸣检查

每章写完后问自己：

1. **读者会担心什么？** → 说不清=没有张力
2. **角色失去了什么？** → 没有失去=没有代价
3. **读者对角色的理解变了什么？** → 没有变化=流水账
4. **有没有一个让人停下来想的细节？** → 没有=没有余韵
5. **情绪是通过行动展示的吗？** → 直接写情绪=叙述

## 九、自检清单

### 连贯性
- [ ] 与世界观有无矛盾？
- [ ] 与前文有无矛盾？
- [ ] 人物言行是否一致？
- [ ] 时间线是否合理？
- [ ] 伏笔是否正确埋入/回收？

### 质量
- [ ] 每个场景都有冲突吗？
- [ ] 场景结束时情况发生了变化吗？
- [ ] 章节开头100字内有钩子吗？
- [ ] 章节结尾有钩子吗？
- [ ] 有没有"流水账"段落？
- [ ] 对话是否在推进剧情或揭示性格？

### 去AI味
- [ ] 禁用词表扫描通过？
- [ ] 段落不超过3句？
- [ ] 有没有"总结升华"式结尾？
- [ ] 对话口语化吗？
- [ ] 节奏有没有打破均匀感？
- [ ] "AI不敢写"测试通过？

### 情感共鸣
- [ ] 读者会担心角色吗？
- [ ] 角色有失去什么吗？
- [ ] 有没有让人停下来想的细节？
- [ ] 情绪是通过行动展示的吗？

## 十、自检口诀

```
一段不过三句话。
对话要像人说话。
心情不写心里话。
结尾不搞大升华。
打斗不写流水账。
日常要埋伏笔桩。
禁用词表扫一遍。
AI不敢写放一句。
```
