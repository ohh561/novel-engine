# 自审系统

> ⚠️ 每写完一章，必须运行自审。发现问题立刻纠正，不要等到后面。
> 自审不是走过场，是真的找问题。

---

## 自审流程

写完一章后，以**读者/批评者**的身份重新读一遍，逐项检查：

### 一、逻辑一致性

**世界观逻辑：**
- [ ] 屏障频率变化是否按**故事时间线**推进？（不是按章节！）
- [ ] 魔力/灵能/以太的设定是否前后一致？
- [ ] 角色的能力是否符合当前阶段？（不能突然变强/变弱）
- [ ] 时间线是否合理？（一章覆盖多少天？和上一章的时间间隔？）

**数值逻辑：**
- [ ] 所有数字是否合理？（频率、距离、人口、战力等级……）
- [ ] 数值变化是否有依据？（不能为了"感觉"而随意改数字）
- [ ] 如果一个设定在前文出现过，这一章是否一致？

**因果逻辑：**
- [ ] 角色的行为是否有动机？（不能为了推动剧情而让角色做不合理的事）
- [ ] 事件的发生是否有因果链？（不能"突然就发生了"）
- [ ] 如果A导致B，B导致C，A→B→C的链条是否完整？

**反面检查（最容易犯的错）：**
- [ ] 有没有"按章节推进"而非"按故事时间推进"的设定？（如频率每章下降）
- [ ] 有没有"前文有设定，后文忘了"的情况？
- [ ] 有没有"角色突然变蠢"以推动剧情？
- [ ] 有没有"方便的巧合"？（巧合可以有一次，不能有两次）

---

### 二、节奏与吸引力

**节奏检查：**
- [ ] 这一章有没有"无聊的段落"？（读的时候会跳过的部分）
- [ ] 节奏是否和内容匹配？（紧张场景用短句，舒缓场景用长句）
- [ ] 有没有"流水账"？（时间在推进但什么都没发生）
- [ ] 章节长度是否合适？（3000-5000字，核心场景可以更长）

**吸引力检查：**
- [ ] 这一章有没有一个"让人想继续读下去"的点？
- [ ] 开头100字有没有钩子？
- [ ] 结尾有没有钩子？
- [ ] 如果把这章删掉，会影响读者体验吗？（不影响就该删）

**读者视角：**
- [ ] 读者读到这里会担心什么？（说不清=没有张力）
- [ ] 读者读到这里会期待什么？（说不清=没有悬念）
- [ ] 读者读到这里会有什么感受？（说不清=没有情感共鸣）

---

### 三、人物一致性

**性格检查：**
- [ ] 林晨这一章的表现是否符合他的性格锚点？（不服、聪明、闷骚）
- [ ] 其他角色的言行是否符合他们的性格档案？
- [ ] 角色的说话方式是否和之前一致？（老周粗犷、苏薇理性、陈卫国简洁）

**关系检查：**
- [ ] 角色之间的关系是否和当前阶段匹配？
- [ ] 关系的变化是否有铺垫？（不能突然变好/变坏）
- [ ] 如果有新角色登场，是否和已有角色有互动？

**成长检查：**
- [ ] 林晨在这一章有没有学到什么/失去什么/改变什么？
- [ ] 如果没有，这一章对他的成长有没有推动？
- [ ] 角色的状态变化是否记录在了 protagonist.md 的"最近三章快照"中？

---

### 四、伏笔检查

- [ ] 本章埋入的伏笔是否记录在 foreshadow.md？
- [ ] 本章推进的伏笔是否有实质进展？
- [ ] 本章回收的伏笔是否自然？（不能太刻意）
- [ ] 有没有"前文埋了，这章该回收但忘了"的情况？
- [ ] 伏笔编号是否正确？（V{N}-F{ID} 格式）

---

### 五、去AI味检查

- [ ] 禁用词表扫描通过？
- [ ] 段落不超过3句？
- [ ] 有没有"总结升华"式结尾？
- [ ] 对话口语化吗？
- [ ] "AI不敢写"测试通过？

---

## 问题记录格式

自审发现问题后，记录在章节末尾：

```
## 自审记录

**发现问题：**
1. [问题描述]
2. [问题描述]

**纠正措施：**
1. [怎么改]
2. [怎么改]

**已纠正：** ✅ / ❌（如果没纠正，说明原因）
```

## 常见错误清单

以下是写长篇小说最容易犯的错误，每次自审重点检查：

| 错误类型 | 例子 | 如何避免 |
|---------|------|---------|
| **按章节推进设定** | 频率每章下降0.2秒 | 设定变化必须按故事时间线，先算好时间再写 |
| **前文有后文忘** | 前面说屏障频率3.7秒，后面变成3.5秒但没解释 | 每章写之前检查 foreshadow.md 和 timeline.md |
| **角色突然变蠢** | 聪明的主角突然做了一个很蠢的决定 | 检查角色性格档案，行为必须有动机 |
| **方便的巧合** | 正好遇到一个人，正好知道关键信息 | 巧合可以有一次，不能有两次 |
| **数值不合理** | 一章之内频率从3.7降到2.9 | 先算清楚时间线和数值变化速率 |
| **信息倾泻** | 角色突然用大段独白解释剧情 | 用行动和对话自然揭示 |
| **重复描写** | 连续几章用同样的方式描写战斗 | 每次战斗要有不同的角度和重点 |
| **情感断裂** | 上一章还在悲伤，这一章突然开心 | 情感变化需要过渡 |
