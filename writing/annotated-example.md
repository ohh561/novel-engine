# 带注释的示例

> 本文件对一个示例段落进行注释，说明用了什么写作技术。
> 新用户可以通过这个示例理解系统如何在实际写作中运作。

---

## 示例段落

> 等号少了一个。
>
> 他盯着屏幕第四十七行看了三秒，把`=`改成`==`，敲下回车。终端刷出一串绿字，测试全过。他往椅背上靠，椅子吱呀叫了一声，像踩了一只老鼠。

---

## 注释

| 元素 | 技术 | 说明 |
|------|------|------|
| "等号少了一个。" | **动作中段切入**（钩子技术） | 不从"他在修bug"开始，直接从修bug的瞬间切入。100字内有钩子。 |
| "第四十七行" | **具体细节**（展示不叙述） | 不说"他在修代码"，给具体行号。让读者"看到"画面。 |
| "椅子吱呀叫了一声" | **感官细节**（去AI味） | 听觉描写。每300字至少一个感官细节。 |
| "像踩了一只老鼠" | **冷幽默**（角色声音） | 角色的说话风格——冷幽默、程序员思维。 |
| "把`=`改成`==`" | **专业细节**（角色一致性） | 程序员背景的真实感。 |

## 对话示例

> 手机响了。屏幕亮起一个"妈"字。
>
> 他盯着看了两秒。接了。
>
> "吃饭了吗？"
>
> "吃了。"
>
> "吃的什么？"
>
> 他瞟了一眼桌上那桶泡面，汤已经凉了，面糊成一团。
>
> "蛋炒饭。"

---

## 注释

| 元素 | 技术 | 说明 |
|------|------|------|
| "屏幕亮起一个'妈'字" | **具体细节** | 不说"妈妈打来电话"，用屏幕显示的细节。 |
| "他盯着看了两秒。接了。" | **短句**（节奏控制） | 犹豫的动作——用具体时间"两秒"展示，不叙述"他犹豫了"。 |
| "瞟了一眼桌上那桶泡面" | **展示不叙述** | 不说"他穷得只能吃泡面"，让读者自己看到泡面。 |
| "蛋炒饭。" | **对话潜台词** | 说的和想的不同——他在撒谎。对话推动性格揭示。 |

---

## 技术清单

| 技术 | 说明 |
|------|------|
| 动作中段切入 | 开头直接进入场景，不铺垫 |
| 具体细节 | 用数字、名称、感官让画面真实 |
| 展示不叙述 | 用行动让读者自己"看到"，不直接告诉读者 |
| 对话潜台词 | 角色说的和想的不同 |
| 冷幽默 | 角色独特的说话方式 |
| 短句节奏 | 紧张时刻用短句，舒缓时刻用长句 |
| 钩子（开头） | 100字内必须有吸引力 |
| 钩子（结尾） | 必须有钩子让读者想继续读 |
